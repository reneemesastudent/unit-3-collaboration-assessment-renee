1. When collaborating with a classmate, the first step you should complete is adding them to your codespace. If you don't complete this step your partner won't have access to your files and won't be able to work along side with you. You can do this by first clicking settings, then clicking collaborators. When doing this, scroll down until you see the "add collaborators" button. Click it and then add your partners email or username. Your partner must then enter their gmail and accept your request. 
2. Developers use branches so that when working, their work won't immediately save to their main branch and they are able to make changes.
Git is a specific open source version control system. Github is a company that offers a cloud-based Git repository hosting service. They work together because github is a more user-friendly coding area while Git is for more advanced users who know their way around computers. 
4. The correct command sequence should be git add ., git commit -m "saving work", and then finally git push. If the steps are missed are carried out incorrectly, the saving process will not work.
